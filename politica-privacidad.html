Política de Privacidad — Lobito Publicador

Última actualización: 27 de octubre de 2026

Qué es esta aplicación

Lobito Publicador es una herramienta personal del propietario de las Páginas de Facebook Historias de Madrugada, Págate Primero y Tech: IA al Dia, y de sus cuentas de Instagram vinculadas. Su única función es publicar el contenido propio del propietario en sus propias Páginas y cuentas, usando la API oficial de Meta, bajo su autorización.

Qué datos utiliza

La aplicación utiliza tokens de acceso de las Páginas del propietario y la información básica de esas Páginas y cuentas (nombre e identificador) que la API de Meta necesita para publicar contenido. No recopila datos personales de terceros, no vende ni comparte información con nadie, y no se usa para publicidad ni para rastreo de personas.

Almacenamiento y seguridad

Los tokens de acceso se guardan en almacenamiento seguro y se usan únicamente para las publicaciones autorizadas por el propietario. Cada publicación realizada queda registrada en una bitácora del propietario.

Revocación y eliminación

El propietario puede revocar el acceso de esta aplicación en cualquier momento desde Facebook → Configuración → «Apps y sitios web». Al revocarlo, los tokens dejan de funcionar de inmediato y la aplicación ya no puede publicar ni acceder a dato alguno. Para solicitar la eliminación de cualquier información asociada, el propietario puede comunicarse a través de las propias Páginas de Facebook listadas arriba.

Eliminación de datos de usuario

Esta aplicación no almacena datos personales de los visitantes o seguidores de las Páginas y cuentas mencionadas. Si en algún momento deseas solicitar la eliminación de cualquier información asociada a ti, puedes hacerlo escribiendo a través de cualquiera de las Páginas de Facebook listadas arriba; la solicitud se atiende eliminando la información asociada en un plazo razonable. La revocación del acceso de la aplicación (descrita en la sección anterior) detiene de inmediato todo uso de tokens.

Cambios a esta política

Si esta política cambia, la versión vigente estará publicada siempre en esta misma página.
